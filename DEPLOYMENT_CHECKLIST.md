# 5-minute deployment checklist

1. Create a GitHub repo.
2. Upload this entire folder.
3. Settings → Pages → Deploy from branch → `main` / root.
4. Actions → run `BrewScope Market Monitor` manually once.
5. Open the Pages URL.
6. Check the **Monitor** tab.
7. For future changes, GitHub Actions refreshes the source snapshots daily.

For the capstone demo, show:
**Market → Monitor → Gap → Decision**.

For the submission, include the report + AI audit log + dataset + this GitHub repository URL.
